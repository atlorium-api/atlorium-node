# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [0.1.0] — 2026-10-03

Первый релиз.

### Добавлено

- Клиент `Atlorium` без рантайм-зависимостей на встроенном `fetch`: Node.js 20+, Bun, Deno, edge-среды;
  сборки ESM и CommonJS с типами.
- Все 23 сервиса Atlorium, 59 методов: ЕГРЮЛ/ЕГРИП, БИК, SWIFT, BIN, AML, профиль IP, ГАР/ФИАС,
  стандартизация адреса, телефон, e-mail, OCR, DNS, CIDR, cron, SSL, погода, ИИ-чат, прямой и обратный
  геокодинг, тестовые данные, проверка ссылок, аудит сайта, модерация изображений.
- Типы параметров и ответов по сервисам (`Egrul`, `Cbr`, …), сгенерированные из OpenAPI-спек.
- Классы ошибок по HTTP-статусам, ретраи на 429/503 и сетевых ошибках с учётом `Retry-After`,
  таймауты и отмена через `AbortSignal`.
- `PermissionDeniedError` для ответа 403: сервис не входит в условия учётной записи
  (код `service_not_in_account_terms`). Не повторяется.
- `ServiceUnavailableError` (503) — наследник `ServerError`: `instanceof ServerError` ловит любой 5xx.
- `retryAfter` (секунды из `Retry-After`) есть у любой ошибки, а не только у `RateLimitError`.
- 503 с кодом `service_disabled` или `maintenance` (плановые работы) не повторяется; прочие 503 повторяются.
  Если сервер просит ждать дольше двух минут, сразу бросается ошибка по статусу: `RateLimitError` для 429,
  `ServiceUnavailableError` для 503.
- Метаданные ответа через `withRawResponse`.
- `fileFromPath` в точке входа `atlorium/node` (типы доступны и при `moduleResolution: node10`).
- Демо-режим без ключа на публичном sandbox-ключе; если ключ не задан вовсе — одно предупреждение
  `console.warn` за процесс.
- POST после сетевой ошибки повторяется, только если соединение не установилось: повтор после таймаута
  мог бы выполнить платную операцию второй раз.
- Отмена через `signal` прерывает и ожидание перед повтором.
- Путь к файлу или ссылка вместо Base64 в `ocr`/`imagecheck` — понятная ошибка с подсказкой про `fileFromPath`.
- Таймаут `aichat.send` по умолчанию — 660 с (11 минут): развёрнутый ответ модели может готовиться
  несколько минут. Явный `timeout` вызова важнее.
- `options.fetch` принимает любую совместимую с `fetch` функцию, в том числе `fetch` из пакета `undici`,
  без приведения типов (типы `Fetch`, `FetchInit`, `FetchResponse`).
- `npm version` обновляет `src/version.ts` вместе с `package.json`.
